Barème des infractions courantes
Idée-clef

La classe détermine le forfait ; l’article de l’infraction fixe les points. Les deux ne vont pas ensemble : le clignotant omis coûte 35 € et 3 points.

Forfaits ordinaires, là où l’amende forfaitaire s’applique. Sélection, pas barème complet. Jeune conducteur : mêmes retraits de points, mais capital initial de 6 — voir R7.

Piège — l’amende ne dit rien des points Clignotant omis : 2e classe, 35 €, 3 points. Feu jaune fixe : 2e classe, 35 €, 0 point. Stationnement : jamais de points. Bande d’arrêt d’urgence : y circuler = 4e, 3 points ; s’y arrêter = 2e, 0 point.
D’où viennent les chiffres Montants : code de procédure pénale (R49) — 11 · 35 · 68 · 135 €, et 200 € pour certaines contraventions de 5e classe. Points (du conducteur seulement) : dans l’article qui définit l’infraction — pas dans R223-3.
